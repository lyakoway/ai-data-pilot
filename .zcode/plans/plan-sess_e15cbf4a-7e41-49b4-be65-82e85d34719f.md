# Ксюша v2: загрузка документов + просмотр — ВСЁ существующее сохраняется

## Ключевой принцип

**Ничего не ломаем.** Ксюша продолжает отвечать по встроенной док-базе (metrics_dictionary, data_lineage, backend_logic), как сейчас. Новые возможности — чисто аддитивные:

1. Пользователь **дополнительно** загружает свои файлы (PDF, DOCX, TXT, MD)
2. Ксюша ищет **по обоим** источникам: встроенные доки + загруженные файлы
3. Source cards открывают **просмотрщик документа** (PDF на нужной странице, DOCX рендер, TXT текст)

## Поток данных

```
1. Drag&drop PDF → POST /api/documents → parse → chunks → app.db
2. Вопрос Ксюше → retrieve() ищет:
   a) chunks из загруженных документов (BM25-IDF scoring)
   b) built-in docs (текущий keyword search)
   c) объединяет, top-4
3. LLM: контекст + правило цитировать [1] → ответ
4. Source [1]: filename, page, document_id
5. Клик по source → DocumentViewer:
   - PDF: <iframe src="/api/documents/{id}/file#page=3">
   - DOCX: docx-preview рендер
   - TXT/MD: <pre> текст
   - Built-in: показывает текст чанка (как сейчас)
```

## Поиск: улучшение, не замена

Текущий keyword-overlap остаётся для built-in docs. Для загруженных документов — BM25-IDF (редкие слова весят больше, нормализация на длину). Оба результата объединяются в один ranked list.
